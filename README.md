# PathFinder 


مستودع خاص بمشروع **PathFinder**
( تحديد مسار الطالب مندفع ام متروي من خلال اختبار الصور المتطابقه 
تقوم الواجهه بحفظ الوقت و الاجابه وإرسالها إلى السيرفر من ثم يتم مقارنه ب الإجابه  الصحيحة ويتم تحدد مسار الطالب عن طريق المعادلة:
الاخطاء /الزمن 

**قيد الانشاء**
من ثم يتم توجيه الطالب إلى واجهه تساعد في تحسين اداه سوا كان متروي او مندفع)
 Laravel المبني باستخدام إطار العمل 
 لتقديم خدمات الـ API.
##  حالة المشروع (Project Status)
**المشروع قيد التطوير الحاضر:** ما زلت أعمل على تطوير الميزات وإكمال بقية الأجزاء.
**التحديثات القادمة:** إضافة المزيد من الـ APIs، تحسين الأداء، وتطوير واجهات إضافية اضافه Middleware
خاصه للطالب و اخر للادمن .



## 📌 مميزات المشروع (Features)
* بناء APIs متكاملة ومنظمة.
* إعدادات حماية متقدمة (مثل Rate Limiting و CORS).
* هيكلة وإدارة قواعد البيانات بشكل مرن.

##  التقنيات المستخدمة (Tech Stack)
* **Backend:** PHP & Laravel Framework
* **Database:** MySQL
* **Frontend:** HTML, CSS, JavaScript, Bootstrap
